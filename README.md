# Шахматная школа Александры Димитровой

Одноэкранный сайт: https://gifdjim-ops.github.io/guninachess/

Адаптивный фон из двух предоставленных изображений, три прямые ссылки на сообщества, плавание кнопок и круговая заливка из точки входа курсора. Анимация отключается при системной настройке уменьшения движения. Работает без внешних библиотек, шрифтов и JavaScript для переходов по ссылкам.

Публикация: GitHub Pages, ветка main, корень репозитория.

Контент находится в index.html, оформление в style.css, интерактивность в script.js.
